# 🚀 Sourav Kumar | 3D Interactive Portfolio

An immersive, high-performance personal portfolio website built with **HTML5, CSS3, Vanilla JavaScript, and Three.js**. It features a multi-stage 3D universe complete with an interactive 3D robot coder avatar, dynamic lighting, custom cursor effects, and smooth section-morphing animations.

---

## ✨ Key Features

- **🤖 Interactive 3D Robot Coder (Stage 1):** Powered by Three.js, featuring real-time mouse/touch cursor tracking (yaw, pitch, roll), natural cartoon blinking eyelids, cyber glasses, and glowing headphones.
- **🌌 Serene 3D Cyber Constellation (Stage 2):** A dynamic holographic matrix and particle constellation that morphs as you explore your skills.
- **🪐 Zen Horizon Geometry (Stage 3):** Clean geometric rings and ambient stardust fields for a calm, professional contact experience.
- **⚡ Custom Minimalist Cursor & Ripple FX:** Smooth follower dots with eye-comfort click ripples and micro-pulse animations.
- **💻 Responsive & Mobile-Optimized:** Fluid layouts designed with modern glassmorphism (`backdrop-filter`) and CSS custom properties for supreme readability and aesthetic flair.
- **✉️ Direct Mailto & Clipboard Form:** Integrated contact form with automated email client prep and instant copy-to-clipboard feedback.

---

## 🛠️ Tech Stack

* **Frontend Core:** HTML5, CSS3 (Flexbox & CSS Grid), ES6+ JavaScript
* **3D Graphics:** Three.js (WebGL rendering engine)
* **Styling & Effects:** Glassmorphism, CSS Custom Properties, Keyframe animations
* **Icons:** Font Awesome 6.5.1
* **Fonts:** Google Fonts (*Inter* & *Poppins*)
